# Python Payments Analysis 📊

Projeto de análise de pagamentos desenvolvido em Python com foco em análise de dados, indicadores e visualização.

## 🎯 Objetivo

Utilizar Python e Pandas para analisar dados fictícios de pagamentos, identificar padrões e gerar indicadores que possam apoiar decisões de negócio.

## 🛠️ Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Análise de dados
- Visualização de dados

## 📊 Análises realizadas

O projeto apresenta análises de:

- Quantidade total de pagamentos
- Valor total movimentado
- Ticket médio
- Pagamentos por status
- Pagamentos por método
- Pagamentos por cliente
- Evolução dos pagamentos por período
- Clientes com maior volume financeiro

## 💡 Insights

A análise busca transformar dados de pagamentos em informações úteis para o negócio, permitindo identificar comportamento dos clientes, desempenho dos pagamentos e oportunidades de melhoria.
